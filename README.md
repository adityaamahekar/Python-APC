
# 🐍 Advanced Python Programming

A collection of Python programs and practical exercises developed as part of the **Advanced Programming Concepts (APC)** course.

This repository covers Python fundamentals, data structures, object-oriented programming, file handling, numerical computing, data visualization, GUI development, and web development.

## ⚙️ Requirements

- Python 3.10 or later
- Visual Studio Code or another Python IDE
- Required Python libraries

### Install Required Libraries

```bash
python -m pip install numpy pandas matplotlib
```

For Django:

```bash
python -m pip install django
```

Tkinter is included with many Python installations.

## 🚀 How to Run

**Step 1:** Clone the repository.

```bash
git clone https://github.com/YOUR-USERNAME/Advanced-Python-Programming.git
```

**Step 2:** Open the project folder in VS Code.

**Step 3:** Navigate to the required practical folder.

**Step 4:** Run the Python program.

```bash
python program.py
```

Replace `program.py` with the actual filename.

### Running Django Projects

Navigate to the directory containing `manage.py`.

```bash
python manage.py migrate
python manage.py runserver
```

Open the following URL:

http://127.0.0.1:8000/
